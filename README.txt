JELAJAH MOJOKERTO - TEMPLATE HTML/CSS

Cara pakai:
1. Masukkan foto/gambar ke folder assets.
2. Gunakan nama file berikut agar langsung terbaca:
   - hero-mojokerto.jpg              = gambar background halaman utama
   - logo.png                        = logo Jelajah Mojokerto
   - karakter.png                    = karakter pada bagian Tentang Produk
   - login-bg.jpg                    = background halaman login
   - karakter-membawa-kaca-pembesar.png = karakter halaman login
   - avatar.png                      = foto/avatar pengguna
   - map-mojokerto.jpg               = background peta halaman jelajah
3. Buka index.html.
4. Tombol LOGIN menuju login.html.
5. Tombol Masuk menuju jelajah.html.

Catatan:
Template ini dibuat berdasarkan rancangan PDF Jelajah.pdf. Login masih berupa tampilan/front-end sederhana, belum terhubung database.
